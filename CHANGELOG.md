# Changelog

## 0.1.0-beta.2

This beta expands Narrately's supported-site coverage and makes narration
controls and troubleshooting more reliable.

### New site support

- **Cyrisia:** Narrately can read a book's EPUB sections when they are rendered
  in same-origin frames, and can fall back to readable inline chapter text.
  Recognized chapter headings are used where available. Sequentially numbered
  parts of the same chapter are combined into one chapter.
- **Novel Archive:** Narrately can read the current reader page, including the
  novel title, chapter title and chapter text. Translator and editor credit
  lines are omitted from the narration.
- **Lnori:** Sequentially named parts of a chapter are grouped together, so a
  multi-part chapter appears as one chapter in the chapter picker.

### Player and troubleshooting improvements

- Changing the speed after a chapter has been prepared now takes effect during
  playback without generating the audio again.
- The speed slider responds to the mouse wheel. Using it no longer scrolls
  the panel unintentionally, and its keyboard events no longer trigger page
  navigation shortcuts behind the panel.
- A separate **Debug** window collects Narrately warnings and errors from its
  extension contexts. Review the captured logs and copy them into a bug report
  when asking for help.
- Added a bug-report template to help include the details needed to investigate
  reported problems.

### Compatibility and installation

- Supported browser minimums remain Chrome 121 and Firefox 128.
- As before, download the Chrome or Firefox package from the project's
  Releases page. The voice model is downloaded separately when first needed.

### Maintenance

- Removed the unused, outdated content extractor in favor of the site-adapter
  implementation.
- Consolidated ignore rules at the repository root. The build now removes the
  nested `.gitignore` generated by `wasm-pack`.

## 0.1.0-beta.1

First beta. The UI shows a Beta badge for pre-releases.

- Local narration with Kokoro-82M (Rust/WASM core, TypeScript, no cloud service or API key).
- In-page panel: chapter picker, voice, speed, text preview, progress with time estimate, player with seek/skip/download. The whole chapter is prepared first; preparation continues in the background if the panel is closed.
- One-click in-panel model download (checksum-verified, stored on the device); optional WebGPU mode with its own model.
- Chrome and Firefox builds. Publishing a GitHub release builds and attaches them (see [docs/releasing.md](docs/releasing.md)).
